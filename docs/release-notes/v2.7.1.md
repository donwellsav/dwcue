# DonWells Cue 2.7.1

This release fixes four problems found after 2.7.0: two with Video Output and two with QuickPlays. Show files are stored exactly as in 2.7.0.

## Read this before updating

- **Choose the video output display each time you start the app.** DonWells Cue no longer remembers screens from one run to the next. Picture framing and test card settings are still kept. A display chosen in an earlier version is ignored.
- **Shows move freely between 2.7.0 and 2.7.1.** Nothing about the show file has changed.
- **Update a remote audio engine too.** The QuickPlay Restart fix is in the engine, and the Pre-show check reports an app and engine of different versions.

## Video Output

- **The video window no longer closes by itself when it goes full screen on a computer with one screen.** It could close when an earlier session had chosen a display that was not connected. Now only an output whose own display is unplugged closes; the preview window is never closed by display changes.
- **Screens are chosen fresh each launch.** The output display and the capture display hold until you quit and are never saved.
- **The picture returns with its display.** If the output's display drops out and you reopen Video Output before it comes back, the preview opens on the control screen as before. When that display returns, the preview becomes the full-screen output on it. Plugging in any other screen leaves the preview where it is.

## QuickPlays

- **Retrigger: Restart works.** Pressing a QuickPlay while it plays starts it again from its In point, sound and picture. Before, it carried on from where it was. Retrigger: Ignore still leaves it playing.
- **Key labels fit on every tile.** The attached QuickPlay panel opens 336 pixels wide instead of 300, so each tile shows its number, key, time and edit buttons on one line. Dragging the panel narrower than about 330 pixels cuts the labels off again.
- **The playlist opens 36 pixels narrower** to make that room. Its Import, Add Group and Shuffle Playlist buttons keep their names at the default window size, also when the Keep Music Going button is beside them.

## What was checked, and what was not

- Every release build starts the packaged audio engine on Windows and macOS and requires it to answer as this version before an installer is published.
- On macOS: client type checking and 462 client tests, the 13 engine unit-test suites (one now also covers QuickPlay Restart and Ignore) and the 104 engine network tests passed at 2.7.1, and the packaged Apple Silicon app passed its engine self-test. The QuickPlay tiles and the playlist bar were measured in the packaged app.
- Not yet checked: unplugging and replugging a real projector, and any of these fixes on Windows. Rehearse Video Output on the show machine before relying on it. The wrong-screen correction on a Windows computer with two displays at different scaling, listed in the 2.7.0 notes, is also still unchecked on real hardware.
