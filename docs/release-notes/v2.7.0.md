# DonWells Cue 2.7.0

This release makes a running show easier to read at a glance, puts the picture on the right screen and only that screen, and adds the checks and backups to prepare a show with confidence. It also changes how QuickPlays are stored, so read the first section before updating a machine you share shows with.

## Read this before updating

- **Update every computer that opens your shows together.** Shows saved by earlier versions open in 2.7 with nothing lost. A show saved by 2.7 opens in 2.6 with its playlist but without its QuickPlays. They stay in the file and return when the show is opened in 2.7 again, along with any QuickPlays added in 2.6 meanwhile.
- **The app and a remote audio engine must be the same version.** The Pre-show check reports a mismatch.
- **MIDI files, tracker modules and game-console music no longer play.** A cue that uses one will not load. Convert those files to WAV, FLAC or MP3 before updating. MIDI controllers are not affected.
- **The first online import, and the first video conversion, download their converter once.** The computer needs the internet for that one time; it is no longer part of the installer.
- **External controllers:** the address a cue shows in Properties is unchanged. If a controller triggers a QuickPlay by slot number, its address is now `/api/transport/quickplay/<slot>/play` (it was `/api/transport/cart/<slot>/play`).
- **Windows:** the installer no longer creates the "DonWells Cue Server" desktop shortcut, and removes it when upgrading.

## Running the show

- **Red is live, green is next.** Playing rows and QuickPlays have a red edge, a red number and a "Playing" badge. The Up Next row is green. The two also differ by shape, so they can be told apart without relying on colour.
- **Stop is never red.** Stop All and every cue's Stop button sit in yellow-and-black hazard stripes.
- **The countdown is a stop light:** green, then yellow, then red, on the live row's time and on Time Left. It stays readable on the light theme.
- **List Left** is a third clock: the rest of the playing cue plus everything after it.
- **Find cue** on the playlist jumps to a cue by title, note or number without filtering the list. Ctrl/Cmd+F puts the cursor there, and Escape is still Stop All while you type.
- **Two locators** on the playlist bar scroll to the live cue and to Up Next.
- **Every row shows its level** with up and down steps of half a dB, and can carry a note beside its title (double-click or F2 in Edit Mode).
- **Show Mode is Edit Mode with the editing taken out.** Nothing moves or changes size when you switch; the controls you do not need during a show are simply gone.
- **The shortcut bar has two lines** and lists every keyboard action, the show-running keys first.
- **The computer stays awake** while a show is open, and the display stays on in Show Mode and while a cue plays.

## QuickPlays

- A QuickPlay now has the **full Properties panel** a playlist cue has: fades, trims, transitions and endings, with its own settings for what happens when it is triggered again.
- **Cue to Continue** is a toggle on the tile. It applies to the pass that is playing and is never saved into the show.
- **The level is on the tile**, and the tile is laid out as number, time, name and one row of controls. The number is a chip in the tile's own colour.
- **Ten QuickPlays show by default** in the attached panel and **twenty** in the detached window.

## Preparing a show

- **Pre-show check** (Settings > Audio Routing) reads the engine, the outputs, every cue's media, the show file and the video check in one panel, without starting anything. Level Check is beside it.
- **Show backups.** The engine copies the show file before a save replaces it: at most one every five minutes, ten kept. Settings > Playback Behaviour lists them with Restore. A restore backs up the current show first and is refused while anything is playing.
- **Cue sheet.** File > Export Cue Sheet (PDF) prints the show: cues and groups with number, title, note, duration, level and ending, then the QuickPlays. Chinese and Japanese text prints correctly.
- **Clean Up Media** (File menu, Edit Mode) lists the files in the show's media folder that nothing uses, and moves the ones you tick to the Trash or Recycle Bin. A file is kept if the open show, the saved show, any backup or another show in the folder names it. It works when the audio engine is on this computer.
- **Readable and touchable.** The interface is drawn at 100% instead of 90%, small text is larger, and buttons are large enough to touch. File browsers have more room, and the meters fold to a slim rail.

## Video

- **The output keeps to the one display it was given.** On a Mac it no longer blanks the other screens, whatever the "Displays have separate Spaces" setting. If the assigned display is unplugged, the output closes rather than moving to another screen, even an identical one.
- **The app keeps checking the picture is exactly on its display** and puts it back by itself if it is too small, too large, shifted or on the wrong screen.
- **Escape still runs Stop All,** and no longer takes the audience display out of full screen.
- **Videos this computer cannot show are converted.** ProRes, DNxHD, MPEG-2, Xvid, Motion JPEG, AVCHD and WMV files used to play sound with no picture. The app now makes an H.264 copy beside the original and points the cue at it. The original is never changed, and a conversion steps aside the moment a cue starts. Nothing is converted when the audio engine is on another computer.
- **The video check runs by itself** when the show is idle: on open, after an import, and when a cue's file or trim changes.
- **Captures are saved with the show.** "Capture as standby picture" (G) and "Capture for cue" (Shift+G) save a picture file in the show's media folder. A capture panel shows what was taken, with Undo and Clear.

## Reliability

- **"Local server failed to start" clears by itself.** A stale lock, a busy port or an engine that has stopped answering is recovered without restarting the computer.
- An idle engine left running by an older version is replaced by this version's engine. One with a show open or audio playing is left alone.
- A failed download of an import tool is tried again by the next import instead of asking for a restart.
- The engine's old ten-minute backup timer is retired in favour of the backups made at save time. Copies it already made are left in place.

## Smaller download

The installer no longer carries a second copy of FFmpeg, unused components, or languages the app does not offer. The unpacked Apple Silicon app is about a third smaller than 2.6.24.

## What was checked, and what was not

- Every release build starts the packaged audio engine on Windows and macOS and requires it to answer as this version before an installer is published.
- The interface, QuickPlays, show backups, video conversion and the single-display video output were checked on macOS.
- Not yet checked on real hardware: the wrong-screen correction on a Windows computer with two displays at different scaling. Rehearse Video Output on the show machine before relying on it.
