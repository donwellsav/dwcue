# DonWells Cue 2.8.1

## Video Output

- Choose a supported HDMI signal format directly in Cue on macOS. The default is **1080p59.94**, with explicit 60.00 Hz and supported legacy NTSC choices in Settings. Cue uses active HDMI driver timing when it can read it and keeps the built-in and control screens out of the output picker. Receiver lock still depends on the signal chain and switcher.
- Cue checks the assigned external display again as it reconnects. Closing Video Output releases Cue’s temporary mode and reports if restoration was unconfirmed.
- The picture can fit inside a fixed canvas, fill it with proportional cropping, or match the output window. Frame size adjusts the picture inside fullscreen.
- Press **F** to open Video Output fullscreen or toggle fullscreen where available. Video thumbnails appear in the playlist, and cue Properties can select a frame for the thumbnail, cue image, or standby.

## Live controls

- A playing playlist row has a green **Loop** button. Use the active-cue card, QuickPlay tile, or Stop All for stopping playback.
- The playlist marks actual live sample peaks above **0 dBFS**. The true-peak limiter continues to guard the output ceiling.
- Now Playing shows a larger elapsed time beside the title. Time Left, List Left, and the clock remain in the header.
- Press **/** to locate the playing playlist cue and **?** to locate Up Next.

English labels are ready on the first screen while the selected translations load.

The operator manual covers the new controls, HDMI setup, and receiver-side checks.
