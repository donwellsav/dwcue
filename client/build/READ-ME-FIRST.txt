========================================================================
  DonWells Cue — READ ME FIRST
========================================================================

This app is signed with an Apple Developer ID and notarized by
Apple, so macOS opens it normally — no security warning, no extra
steps.

  1.  Drag "DonWells Cue" into the Applications folder.
  2.  Double-click it. It opens.

  Windows: if SmartScreen appears, click "More info" → "Run anyway".

  Full guide:  https://dwcue.com/#download
  Source:      https://github.com/donwellsav/dwcue
